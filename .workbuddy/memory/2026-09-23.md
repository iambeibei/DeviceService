# 2026-09-23 工作日志

## 修复 device/{id}/event/StepId 主题无法匹配问题
- 根因：`MqttTopic.TryGetEventType` 中 `parts[3]` 先 `ToLowerInvariant()` 后与混合大小写 `"StepId"` 比较，永不匹配 → `DeviceEventHandler.CanHandle` 返回 false，消息被 `MqttMessageWorker` 丢弃并记 "未找到能处理主题" 警告。
- 修复：白名单改为 `"stepid"`；`DeviceEventHandler` 中 `message.Topic.Contains("warn"/"fault"/"StepId")` 改为 `eventType.Equals(..., OrdinalIgnoreCase)`。
- `dotnet build DeviceService.slnx` 通过（0 错误）。
